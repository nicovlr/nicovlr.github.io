Politique de confidentialité

Dernière mise à jour : 24 octobre 2026

Paris Panic est un jeu pour iPhone réalisé par Nicolas Valerino, développeur indépendant (« nous »). Cette page explique quelles données entrent en jeu quand vous jouez et ce que vous pouvez faire. Contact : nico.valerino@gmail.com.

Ce que le jeu collecte lui-même : rien

Pas de compte, pas de connexion, pas de serveur à nous. Le jeu ne demande ni nom, ni e-mail, ni contacts, ni photos, ni micro, ni localisation. Votre progression (records, médailles, galons, compétences) et vos réglages sont enregistrés uniquement sur votre iPhone. Ils sont effacés quand vous supprimez l'app, ou avec Réglages › Effacer la progression dans le jeu.

Publicité (Unity Ads)

Le jeu est gratuit et affiche des publicités via Unity Ads, un service de Unity Technologies. Les vidéos s'affichent quand vous les choisissez (pour continuer une partie ou obtenir un bonus), plus une courte pub toutes les deux parties terminées. Pour diffuser, mesurer et protéger ces publicités, le logiciel Unity Ads intégré à l'app peut collecter directement sur votre appareil :

  • des identifiants : l'identifiant publicitaire (IDFA) uniquement si vous autorisez le suivi, et l'identifiant propre à l'éditeur (IDFV) ;
  • des données techniques : modèle d'appareil, version d'iOS, langue, localisation approximative déduite de l'adresse IP (pays / région), type de réseau ;
  • des données d'interaction : publicités affichées, regardées, terminées ou touchées ; diagnostics comme les erreurs de chargement.

Unity utilise ces données pour afficher et mesurer les publicités (y compris l'attribution SKAdNetwork d'Apple), lutter contre la fraude et, seulement avec votre accord, personnaliser les publicités. Unity est responsable de traitement indépendant de ces données, selon sa propre politique : unity.com/legal/game-player-and-app-user-privacy-policy. Nous ne recevons aucune donnée qui vous identifie, seulement des statistiques publicitaires agrégées.

Vos choix

  • Suivi (iOS) : au premier lancement, iOS vous demande si Paris Panic peut vous suivre dans les apps et sites d'autres sociétés à des fins publicitaires. Si vous refusez, l'identifiant publicitaire n'est pas partagé et les publicités ne sont pas personnalisées. Modifiable à tout moment dans Réglages › Confidentialité et sécurité › Suivi.
  • Consentement (EEE, Royaume-Uni, Suisse) : Unity demande votre consentement avant toute publicité personnalisée. Vous pouvez le revoir ou le retirer à tout moment avec le bouton confidentialité (ⓘ) affiché dans les publicités Unity, qui permet aussi de demander à Unity l'accès à vos données ou leur suppression.
  • Tout effacer : supprimer l'app efface toutes les données du jeu de votre iPhone.

Enfants

Paris Panic ne s'adresse pas aux enfants de moins de 13 ans et nous ne collectons pas sciemment de données les concernant.

Conservation, suppression et droits

Nous ne conservons aucune donnée personnelle. Pour les données collectées par Unity Ads, les règles de conservation de Unity s'appliquent et les demandes se font via le bouton confidentialité des publicités ou la page dédiée de Unity. Le RGPD vous donne des droits d'accès, de rectification, d'effacement et d'opposition : écrivez-nous pour toute question, nous vous aiderons à joindre Unity. Vous pouvez aussi saisir la CNIL (cnil.fr).

Modifications

Si cette politique change, la nouvelle version sera publiée sur cette page avec une nouvelle date.
